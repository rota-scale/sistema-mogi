# Vídeos da demonstração

Vídeos curtos gerados por IA (Higgsfield), sem áudio, reduzidos para 540 px de largura. Servem só para os chamados simulados (`demo = true`): não são gravações reais de Itamogi nem evidência de campo. As versões originais ficam em `brand/casos-de-uso/videos/`.

O nome do arquivo é o id da categoria (`agua.mp4`), com a capa ao lado (`agua.jpg`).
