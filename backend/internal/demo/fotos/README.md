# Fotos da demonstração

Imagens geradas por IA (Higgsfield, GPT Image), reduzidas para 960 px. Servem só para os chamados simulados (`demo = true`): não são fotos reais de Itamogi nem evidência de campo. O servidor carimba cada uma com o aviso de imagem gerada por IA antes de gravar. As versões grandes ficam em `brand/casos-de-uso/fotos/`.

O nome do arquivo é o id da categoria. Categoria sem arquivo usa o cartão desenhado em `demo.go`.
